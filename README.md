# Healthcare Data Analysis Dashboard (Power BI)

This interactive multi-page dashboard analyzes hospital performance across patients, revenue, diseases, treatments, and financial efficiency using Power BI.

## 📊 Features

- KPI tracking: Total Patients, Billing, Avg LOS
- Patient demographic breakdown by age, gender & blood type
- Disease distribution & test result analysis
- Treatment & medication insights
- Hospital performance comparison (Top 20)
- Key influencers & business recommendations
- Hospital stay & financial efficiency trends

## 🚀 Tools Used

- Power BI
- DAX
- Power Query
- Excel / CSV

## 📌 Skills Demonstrated

- Data Cleaning
- Data Visualization
- KPI Design
- Dashboard Storytelling
- Business Insights
